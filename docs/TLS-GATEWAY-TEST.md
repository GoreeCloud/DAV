# Disposable TLS gateway acceptance test

**Status:** CI-only test fixture; not a deployable production proxy configuration.

`tests/TlsGatewaySmokeTest.sh` launches an ephemeral Apache/PHP DAV backend and an
Nginx reverse proxy on a private Docker bridge. The backend has **no published
host port**. The only published listener is the Nginx HTTPS test port bound to
`127.0.0.1` on the CI host. The test creates a short-lived self-signed
certificate for `dav.test` and deletes its private key at exit.

## Coverage

- Rebuild the DAV image from the checked-in Dockerfile and initialize an empty,
  disposable account registry and test user in a fresh Docker volume.
- Terminate actual TLS at Nginx; require certificate-name verification using
  the ephemeral test certificate as the explicit trust anchor. Reject the same
  certificate when it is **not** trusted.
- Verify an HSTS header on HTTPS and a successful authenticated CalDAV
  `PROPFIND` response through Nginx.
- Replace client-controlled `X-Forwarded-Proto` at the gateway, rather than
  passing arbitrary values to the PHP service.
- Allowlist only the observed Nginx bridge IP as `DAV_TRUSTED_PROXIES`. A
  separate, untrusted bridge peer cannot claim `X-Forwarded-Proto: https` to
  bypass the backend's plaintext-request denial.
- Exercise an IP-based Nginx request limit and require an HTTP `429` result.
- Remove test containers, network, volume and certificate material on exit.

The test configuration is intentionally tight (`3r/s` with a burst of `10`) to
make rate limiting deterministically observable. **Do not copy those values
unreviewed into production**: the appropriate rate/burst depends on the number
of DAV requests generated by actual synchronization clients. The test uses
`nginx:stable-alpine` as a disposable CI fixture; a production image must be
pinned to a reviewed digest.

## Run only in an isolated development runner

```sh
bash -n tests/TlsGatewaySmokeTest.sh
bash tests/TlsGatewaySmokeTest.sh
```

Requires Docker Engine with bridge networking, `curl`, and `openssl`. The local
host port defaults to `18443`; override with `DAV_TLS_SMOKE_PORT` if necessary.
Only run this script on a runner dedicated to disposable test workloads. It
builds a local image, creates a temporary Docker network and volume, and
removes those objects when finished. It does not touch GoreeCloud production
credentials, certificates, accounts or volumes.

## Production acceptance not established by this fixture

This is **not** evidence that a real hostname, certificate-issuance and renewal
pipeline, firewall, DNS record, HSTS preload policy, gateway trusted-IP
allowlist, credential-specific throttling, proxy load balancing or client
interoperability works in a deployed environment. Before any public exposure,
independently review ingress paths (ensure the backend is not directly
reachable), certificate lifecycle, logging/redaction, IP attribution through
an outer proxy/CDN, distributed abuse controls, HSTS policy and DAV client
behavior. Keep the PR draft and all deployment gates open until validated.

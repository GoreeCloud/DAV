# Encrypted snapshot transport — disposable CI rehearsal

This test is **not** a production backup or off-site disaster-recovery implementation. `bash tests/EncryptedBackupTransportTest.sh` creates a private, temporary GoreeCloud DAV data directory, a synthetic account and one file, runs the actual PHP `backup:create` and `backup:verify` commands, archives the validated snapshot, and encrypts the archive with GnuPG AES-256 symmetric encryption and a freshly generated disposable passphrase in a private temporary file.

The test removes the unencrypted tar archive, quarantines the original plaintext snapshot, decrypts the ciphertext into a separate folder, revalidates the PHP SHA-256 manifest, checks the recovered file bytes, empty directory, global account record and both SQLite database integrity checks. It also requires rejection of decryption with an incorrect passphrase and a tampered ciphertext file. The fixture cleans up on exit, uses no network, emits no secrets, and never touches production data.

**Not verified:** protecting the original plaintext snapshot during staging, key management and rotation, encrypted-at-rest live storage, independent signing, immutable/offsite storage, transport credentials, retention, disaster-recovery runbooks, representative user data, independent operator restore or production rollback. GnuPG is an isolated test dependency, not a shipped DAV dependency. Do not consider the production encrypted backup and recovery release gate satisfied by a green disposable CI result.

# Competitive objectives

Relevant references: Nextcloud DAV, Radicale, Baïkal, SOGo, and standards-compliant WebDAV/CalDAV/CardDAV services. These are directional architectural references; this file does not assert a fresh feature-by-feature audit of every project.

GoreeCloud DAV aims for: standards-based multi-client synchronization, straightforward self-hosted deployment, private-by-default tenant isolation, recoverable data ownership, disciplined upgrade compatibility, first-party integration contracts, and low-overhead maintenance for a small family deployment. Competitive goals such as granular sharing, delegated calendars, revocable app-specific credentials, robust server-side scheduling, resumable uploads and operational monitoring are **not implemented** and remain acceptance-driven roadmap items.
